# رَصيد · إدارة الراتب والمصروفات

تطبيق ويب شخصي **مكتفٍ بذاته** (ملف HTML واحد) لإدارة راتبك الشهري وتقسيمه ومتابعة مصروفاتك والتزامك بحدّ الصرف اليومي — بتصميم عربي كامل (RTL) ونظام ألوان الحبر البحري والذهب الصحراوي.

لا يحتاج خادمًا ولا قاعدة بيانات. افتح الملف في المتصفح وابدأ، وتُحفظ بياناتك تلقائيًا على جهازك.

---

## المزايا

- **تقسيم الراتب**: توزيع الراتب على الفئات الثابتة والادخار والاستثمار والمصروف الشهري، مع عرض المتبقي غير الموزّع — ولا يبقى ريال غير محسوب.
- **الفئات والميزانيات**: بنود ثابتة (إيجار، فواتير، أقساط، مصروف الوالدين...) مع خيار «تم الدفع».
- **المدخرات والاستثمار**: مخصّص شهري، ورصيد متراكم، وجهة الاستثمار، وهدف ادخار اختياري.
- **المصروف الشهري** (أكل/شرب/بنزين): مخصّص شهري، ومعدّل يومي مفترض يُحسب آليًا، وخانات يومية لتسجيل صرفك.
- **معيار الالتزام**: رسم بياني ونسبة التزامك بالحدّ اليومي، وأيام التجاوز ونسبته.
- **العجز اليومي وعلاجه**: مقدار تجاوزك للحدّ، والحدّ المعدّل المطلوب للأيام المتبقية لتبقى ضمن مخصّصك.
- **السحوبات الطارئة**: سجّل أي سحب غير معتاد من أي مخصّص (ادخار/استثمار/مصروف/فئة/غير موزّع)، فيُخصم من مصدره وينعكس على كل الأرقام والرسم البياني.
- **رسم بياني** يوضّح أين يذهب كل ريال من راتبك (مجموعه = الراتب دائمًا).
- **تنقّل بين الأشهر** مع بيانات مستقلة لكل شهر.
- **حفظ تلقائي** محلي في المتصفح.

---

## بنية الملفات

```
.
├── index.html      ← التطبيق كاملًا (HTML + CSS + JS في ملف واحد)
├── README.md       ← هذا الملف
├── LICENSE         ← رخصة MIT
└── .gitignore      ← تجاهل ملفات النظام والمحررات
```

> **مهم:** يجب أن يكون `index.html` في **جذر المستودع** مباشرةً (لا داخل مجلد) ليعمل GitHub Pages تلقائيًا.

---

## التشغيل المحلي

افتح `index.html` في أي متصفح حديث — لا حاجة لأي تثبيت. كل تعديل يُحفظ تلقائيًا.

---

## النشر على GitHub Pages

1. ارفع الملفات الأربعة إلى مستودع على GitHub (في الجذر).
2. من **Settings → Pages**، اختر: Source = «Deploy from a branch»، والفرع `main` والمجلد `/ (root)`.
3. سيُنشر الموقع خلال دقائق على:
   `https://<username>.github.io/<repo>/`

### بديل: النشر على Vercel
استورد المستودع في Vercel، واتركه يكتشف المشروع كموقع ثابت (Static) — بلا أوامر بناء.

## الحفظ والخصوصية

- تُحفظ بياناتك **تلقائيًا** في متصفّحك عبر `localStorage` فور كل تعديل.
- البيانات تبقى بعد إغلاق الصفحة وإعادة فتحها، ولا تُرسل إلى أي خادم.
- البيانات مرتبطة بالمتصفح والجهاز، وتُمسح فقط إذا مسحت بيانات الموقع من المتصفح.
